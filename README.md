🎳 Kuglaško Prvenstvo - Seminarski rad
Aplikacija za upravljanje i praćenje rezultata kuglaškog prvenstva, razvijena u sklopu seminarskog rada. 

📋 O projektu
Softver je razvijen korišćenjem C# programskog jezika i .NET Framework platforme, uz primenu Windows Forms tehnologije za izradu korisničkog interfejsa i SQL Server baze podataka za pouzdano skladištenje podataka. 
Osnovni cilj rada bio je da se obezbedi jednostavan, intuitivan i pregledan način za upravljanje podacima (unos, izmena, brisanje i prikaz) o timovima, igračima i ostvarenim rezultatima, uz napredne mogućnosti filtriranja informacija. Takođe, posebna pažnja posvećena je integracionom testiranju, čime je potvrđena stabilnost i ispravnost komunikacije između aplikacije i baze podataka. 

🛠️ Tehnologije
•	Jezik: C# 
•	Platforma: .NET Framework 
•	Interfejs: Windows Forms 
•	Baza podataka: SQL Server
